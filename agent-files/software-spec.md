# 校園設備報修系統：軟體規格書（取消報修功能）

本文件整理自小組 HW1 的「功能需求與開發規格書」，說明系統目標、使用者、功能、限制與完成條件，作為 AI 開發 Agent 判斷需求的依據。

## 系統目標

讓校園使用者可以建立設備報修單、追蹤案件狀態，並在案件尚未處理前自行取消報修，減少無效案件。

## 使用者

- 報修者（學生與教職員）：建立報修單、查看案件、取消自己送出且尚未處理的案件
- 管理者：查看所有案件、更新處理狀態、辨識已取消的案件

## 系統架構

| 層級 | 檔案 | 說明 |
|---|---|---|
| 前台畫面 | `templates/index.html`、`static/app.js` | 報修表單、案件清單、取消報修按鈕 |
| 後台畫面 | `templates/admin.html`、`static/admin.js` | 案件清單、狀態選單與儲存按鈕 |
| 後端 | `app.py`（Flask） | 提供 API、驗證輸入、保存案件 |
| 資料 | `app.py` 內的 `tickets` 串列 | 存在記憶體中，重新啟動後清空 |

## 案件狀態

| 狀態 | 說明 | 可以轉換到 | 由誰轉換 |
|---|---|---|---|
| 待處理 | 新建立的案件 | 處理中、已完成、已取消 | 管理者；取消由報修者 |
| 處理中 | 管理者已開始處理 | 待處理、已完成 | 管理者 |
| 已完成 | 維修完成 | 待處理、處理中 | 管理者 |
| 已取消 | 報修者取消 | 不可再轉換 | — |

## 核心功能

### FR-01 建立報修單

使用者填寫地點、設備、緊急程度、聯絡方式與問題描述，透過 `POST /api/tickets` 建立案件，系統產生案件編號（例如 `T-001`），初始狀態為「待處理」。

### FR-02 案件狀態管理

管理者可在後台透過 `PATCH /api/tickets/<ticket_id>` 將案件改為「待處理」、「處理中」或「已完成」。

### FR-03 取消報修按鈕

前台案件清單中，只有狀態為「待處理」的案件顯示「取消報修」按鈕；其他狀態不顯示。

### FR-04 取消確認

點擊「取消報修」後先跳出確認視窗，使用者確認後才以 `POST /api/tickets/<ticket_id>/cancel` 送出請求。

### FR-05 後端取消檢查

後端確認案件存在且狀態為「待處理」，將狀態改為「已取消」並回傳結果；否則回傳錯誤訊息。

### FR-06 後台顯示已取消

後台以文字顯示「已取消」，不提供狀態選單與儲存按鈕；後端也拒絕修改已取消案件的狀態。

## API 介面

| 方法與路徑 | 用途 | 成功 | 失敗 |
|---|---|---|---|
| `GET /api/tickets` | 取得所有案件 | 200 | — |
| `POST /api/tickets` | 建立案件 | 201 | 400：缺少必填欄位 |
| `PATCH /api/tickets/<ticket_id>` | 管理者更新狀態 | 200 | 400：狀態不正確或案件已取消；404：找不到案件 |
| `POST /api/tickets/<ticket_id>/cancel` | 報修者取消案件 | 200 | 400：案件不是「待處理」；404：找不到案件 |

## 限制與規則

- 地點、設備、聯絡方式與問題描述為必填，未填寫時不得建立報修單。
- 只有「待處理」案件可以取消；取消後保留紀錄，不刪除資料。
- 「已取消」是終止狀態，任何人都不能再改變它。
- 管理者的 `PATCH` 不能把案件設為「已取消」，取消只能透過 cancel API。
- 本版本不處理登入驗證、資料庫與取消原因紀錄；若需求涉及這些項目，應先提出問題。

## 完成條件

| 編號 | 前置條件 | 操作 | 預期結果 |
|---|---|---|---|
| AC-01 | 有一筆「待處理」案件 | 在前台點「取消報修」並按「確定」 | 顯示取消成功訊息，狀態變為「已取消」，按鈕消失 |
| AC-02 | 有一筆「待處理」案件 | 點「取消報修」後按「取消」 | 不送出請求，案件仍為「待處理」 |
| AC-03 | 案件已被改為「處理中」 | 重新整理前台，或直接呼叫取消 API | 前台不顯示按鈕；API 回傳 400 與「只有待處理的案件可以取消」 |
| AC-04 | 案件已取消 | 開啟管理後台 | 顯示「已取消」，無法選擇狀態或儲存 |
| AC-05 | 案件已取消 | 直接呼叫 `PATCH` 修改狀態 | 回傳 400 與「已取消的案件不能再更新狀態」 |
